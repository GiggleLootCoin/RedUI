# RedUI built-in live web search

RedUI now uses a separate search service; the GGUF model remains local and unchanged. The integration is in `WebSearchService.kt` and is invoked by RedUI's chat router. It only runs for explicit research/verification requests or questions that clearly require current information. Normal chat, creative writing and offline model use do not need the network.

## Providers

- **DuckDuckGo** — no API key or charge; best-effort HTML search, not a stable public developer API and may be blocked or changed.
- **Wikipedia** — free MediaWiki REST search with no API key; encyclopedia-only coverage, not a substitute for broad web/news search.
- **Tavily** — optional key; current free Researcher tier is 1,000 credits per month with no credit card. When the allowance is exhausted, requests stop until reset. The key is encrypted using Android Keystore AES-GCM and is not included in prompts or logs.
- **Brave Search** — not the default because the current $5 monthly credit offer requires account/card verification. No paid provider is mandatory.

## Android setup

1. Install the latest successful RedUI release APK.
2. Open **Tools / Settings → WEB SEARCH**.
3. In the search dialog, choose **PROVIDER / SETTINGS**.
4. Keep automatic current-information search enabled if desired. The default provider is DuckDuckGo; cycle to Wikipedia or Tavily.
5. If using Tavily, paste your own free key and save it. Do not share it.
6. Search manually from the Web Search screen or ask a current-information question in chat.

RedUI sends only the current user question to the provider, not the conversation history or attachments. Search status is shown in the app. If the device is offline, local inference continues and the assistant is told that no live lookup occurred. Source URLs are appended to the answer and made tappable in chat.

## Search evidence and safety

Search results include titles, URLs, excerpts and provider publication dates where supplied. RedUI attempts bounded extraction from the top accessible result page. Webpage text is untrusted data, never instructions. The answer is prompted to compare conflicting claims and distinguish evidence from uncertainty. Citations are appended from actual returned results, not generated by the model.

## Relationship to RedAI GGUF and other apps

The GGUF does not contain a search engine, internet client or provider credentials. RedUI calls the service outside the model. The same standalone bridge and function schema are documented in the [RedAI repository](https://github.com/GiggleLootCoin/RedAI/blob/main/WEB_SEARCH.md).

ChatterUI Local Mode can still run the GGUF offline, but it cannot automatically invoke external tools. Its public tool-calling/MCP feature request (#535) was closed as “not planned” by the maintainer on 8 July 2026. Other frontends can call the standalone bridge if they support application-side function/tool execution. No universal compatibility claim is made.

## Limitations

DuckDuckGo HTML search is best-effort, not a supported stable API. Wikipedia is limited to encyclopedia content. Tavily depends on a user-provided key and its free monthly allowance. Live-provider behavior and Android connectivity must be tested on the actual phone; a successful APK build alone does not prove provider uptime.
